# Уточнение теста установленной PWA перед публикацией SC-5

После успешного CI PR #47 повторный workflow main `43277298580` заблокировал публикацию: в чистом WebKit HTML SC-5 вернулся из worker, но модули не запустились. Локальная диагностика затем воспроизвела исчезновение CacheStorage при навигации. Это уточнение заменяет первоначальное предположение о достаточности временного браузерного контекста в отчёте `SC5_PWA_OFFLINE_AUDIT_2026-11-12.md`.

Установленная PWA проверяется в отдельном постоянном профиле, а не в `browser.newContext()` с временным хранилищем. Дополнительно исправлена версия тестового WebKit: Playwright повышен с 1.61.1 до 1.62.1, WebKit — с r2311 до r2336. В исходной версии подтвердился и дефект чтения дискового CacheStorage в постоянном профиле. Его исправление поставщиком описано в [Playwright #41701](https://github.com/microsoft/playwright/pull/41701), связанный разбор — [#41618](https://github.com/microsoft/playwright/issues/41618).

Изменения ограничены средой и доказательствами тестирования:

- Оба сценария — обновление существующей установки и новая установка — используют разные временные каталоги постоянных профилей.
- Перед основным сценарием выполняется запись контрольного ответа в CacheStorage и проверка его сохранности после перезагрузки. Если браузер теряет кэш, причина фиксируется явно.
- При незапуске SC-5 отчёт включает ошибки запросов, ошибки страницы, ответы модулей и состояние её записей кэша.
- При закрытии всех документов приложения остаётся пустое окно без origin приложения. Это необходимо, поскольку закрытие последнего окна завершает постоянный WebKit. Состояние SC-5 в таком окне отсутствует; проверяется новый документ с восстановлением из хранилищ.
- В функциональном мобильном маршруте Студии отключена только CSS-плавность прокрутки тестовой страницы: это устраняет гонку быстрых переходов между полями и нажатием checkbox. Реальные pointer-операции, доступность элементов и проверки ширины сохранены. Код интерфейса не менялся.
- Проверки HTTP-статусов, `fromServiceWorker`, MIME модулей, 15 вопросов, содержимого журналов, отрицательных флагов Студии и отказа неуспешного обновления сохранены. Повторы для скрытия ошибок не добавлены.
- В lockfile изменены только Playwright и playwright-core; зависимости сборки и научного кода сохранены. Исторические сборки используют те же версии React/Vite и других зависимостей сборки, что и первоначальный тест; версия самого браузерного стенда обновлена.

Локально пройдены 234 unit/contract tests, lint, typecheck и PWA-сценарии Chromium/WebKit. Дополнительно выполнены три последовательных WebKit-прогона для проверки воспроизведённой нестабильности. Обязательные CI и мобильные проверки перед публикацией сохраняются.

Изменений в `public-web/public/sw.js`, научных исходниках Chronos AI, интерфейсе или контрактах SC-5 по сравнению с PR #47 нет. Ревизия worker остаётся `sc5-offline-20261112-r1`. Первоначальные границы вывода сохраняются: холодная главная React-игра требует сеть, WebKit с дефектом `setOffline` проверяется при недоступном origin, физический авиарежим iPhone и системная установка «На экран Домой» не проверены.
