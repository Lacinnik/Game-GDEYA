# МОДУЛЬ: доступ к сохранённым паспортам

В разделе «Сохранённые паспорта» доступны записи текущего браузера. Паспорт поддерживаемого формата открывается с исходным ID, формулой, текстом и решением об оси. Просмотр не создаёт новую запись, не пересчитывает результат и не заменяет незавершённый черновик.

После перезагрузки список восстанавливается из существующего журнала. Даты показаны по Москве. Изменение журнала другой вкладкой обновляет список.

Для просмотра проверяется структура `architectonica.module-passport/1.1.0`, соответствие решения заявленной оси и отсутствие наблюдённого Q. Это проверка структуры, не подтверждение достоверности записи. Неизвестные и повреждённые элементы не интерпретируются, но их исходный JSON доступен для скачивания. При повреждении всего журнала показывается ошибка; данные не перезаписываются.

Черновики не сохраняются автоматически. Импорт, редактирование исторических паспортов и межустройственная синхронизация не добавлены. Действующее ограничение хранения — 100 последних записей — не изменено.
