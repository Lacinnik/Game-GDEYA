# Проверка подключения авторского Chronos AI к ГДЕЯ

Дата: 31 октября 2026 года. Исполнитель: Codex по запросу владельца проекта.
Режим: ограниченный инженерный и архитектонический аудит с исправлениями.
Исходный срез: `fbcc68d`, после объединённого [PR №43](https://github.com/Lacinnik/Game-GDEYA/pull/43), merge `afc33767ba60dd741460dda9ce4c2a3fa3682554`.

Граница: браузерная история SC-5 → валидация → связывание событий → авторский движок → итоговый экран. Дополнительно проверены описательный слой лаборатории и согласованность контракта. Только синтетические записи; персональные истории не использовались. Сборка и тесты не подтверждают научную валидность модели.

## Наблюдаемая семантическая граница

При пустых смысловых полях в этой интеграции исходные формулы дают `coherence=.5`, `ambiguity=.664`, `tension=.15`. Это **факт исполнения формул**, не измерение смысла. Два набора с теми же числами и совершенно разным текстом дают идентичный результат. Следовательно, текущий вход не позволяет делать вывод о содержании наблюдений, индукции или инверсии.

`branchProbability`, `shiftProbability`, `continuationProbability` не образуют распределение и не имеют подтверждённой калибровки. В оболочке сохранены `researchOnly=true`, `prediction=false`, `diagnosis=false`, `accessDecision=false`; исторические имена полей внутри авторского алгоритма не превращают числа в научные прогнозы.

## Контуры, переходы и инварианты

| Контур / переход | Предусловие, выход и след | Возврат / ограничение |
| --- | --- | --- |
| Игра → лаборатория | Непрозрачный `cycleId`, фаза `before` / `after` в ссылке | Ссылка не сохраняет ответы и не даёт согласия за участника |
| Лаборатория → localStorage | Явное согласие, первичные ответы, ID, источник, время | Экспорт / удаление истории; общий origin, без проверки личности |
| История → движок | Полная проверка набора; минимум две полные записи одного цикла | Ошибка даёт отказ без синтетического результата; исходная история не изменяется |
| Движок → панель | Новый экземпляр на запуск; версия оболочки, ID событий, ограничения | Старый отчёт очищается; смена цикла удаляет состояние панели |

## Приёмка и воспроизведение

```sh
npm ci
npm run lint
npm run typecheck
npm test
npm run test:mobile
```

`tests/chronos-run.test.mjs` исполняет настоящий TS-адаптер и авторский движок через TypeScript transpile, без моков формул. Проверены границы 0/1, конечность выходов, происхождение и связь событий, отсутствие сетевого ввода/вывода, неизменность хранилища, ошибки источника и движка, повторяемость, часовые пояса, дубликаты, неполные и повреждённые записи.

`tests/e2e/mobile.mjs` проходит игру до итога, сохраняет два полных самоотчёта через UI другой вкладки, запускает кнопку, проверяет нехватку записей, повреждение агрегата/JSON, отсутствие утечки текста ошибки, восстановление, повторный запуск и смену цикла. Встроен в существующую CI-проверку `mobile` (Chromium и WebKit, профиль iPhone 13).

Локально подтверждены lint, typecheck, модульные/интеграционные тесты, production build и полный Chromium E2E. Chromium для локального прогона предоставлен отдельно, без изменения зависимостей репозитория. Локальный WebKit не запущен: отсутствуют системные библиотеки, штатная установка зависимостей недоступна в среде. Результат CI необходимо проверять на точном head SHA PR; список проверок в PR не заменяет их журналы.

## Итог и оставшаяся граница

Инженерные дефекты исправлены в предлагаемой ветке. Статус полного архитектонического аудита: **НЕТ ДАННЫХ ДЛЯ ЗАКЛЮЧЕНИЯ** — он не выполнялся. Готовность конкретного изменения к слиянию определяется проверками точного SHA, включая WebKit; она не означает научной или клинической валидации.

Нет данных для подтверждения личности/контекста участника, независимой валидации SC-5, прогностической точности Chronos, работы на физическом iPhone и опубликованного после этих изменений сайта. Согласие и признаки `false` — проверяемый контракт этого пути, не средство защиты от произвольного другого кода.

Следующий ⊕-шаг: владелец проекта рассматривает diff и журналы CI этой ветки; критерий — успешные проверки и принятие описанной границы числовой эвристики. Для полноценного смыслового пути нужен отдельный контракт входов, согласия и проверки качества; текущий PR такого пути не заявляет.
