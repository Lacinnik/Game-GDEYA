# Несущая линия цифровой Архитектоники · 0.1

Маршрут соединяет шесть самостоятельных точек входа:

`ГДЕЯ → РЕЗОН → Тактика → Материализация → Core Architecture License Lab → Архитектор / Творец Request Gate`.

Каждый переход выпускает отдельный артефакт. Ни один артефакт автоматически не подтверждает следующую ступень, канон, право, доступ или результат.

Последние два публичных инструмента являются подготовительными:

- Core License Lab выпускает досье объёма, но не лицензию.
- Creator Gate выпускает запрос на рассмотрение, но не выдаёт доступ.

`Q` остаётся `null` до отдельного фактического возврата с достаточным основанием.
