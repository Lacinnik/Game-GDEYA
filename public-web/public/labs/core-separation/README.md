# ГДЕЯ · SEP-7×7 · candidate 0.2.0

Встроенный прикладной режим ГДЕЯ для различения источника действия в конкретном эпизоде.

## Инвариант

Влияние допустимо. Присвоение функции выбора — нет.

Контур не измеряет «зрелость» и не диагностирует человека. Он хранит 49 координат `7 законов × 7 жизненных контуров`, один субъектный `⊕-шаг` и наблюдаемый возврат. До возврата `Q=null`.

## TZAR-LANGUAGE-001

Сепарационный профиль общего авторского языкового контура применяет полный корпус `49 Азов × 24 Буки × 7 Передач` к уже различённым координатам `O / S / I / R_g / C`.

- Слово Субъекта выводится человеческим текстом и не заменяется символами.
- Сингулярная формула объясняет происхождение формы отдельно от текста.
- Перед `CONDUCT` субъект явно подтверждает и действие, и получившееся высказывание.
- Паспорт сохраняет модель, профиль, формулу, три верхних кандидата и границы интерпретации.
- После фактического возврата языковой слой обновляет наблюдаемое `Q=0|1`; до возврата `Q=null`.
- Общий набор `tzar-language-evaluation.json` удерживает те же контрольные связки, что и профиль эго-интерфейса; это защита от смыслового дрейфа, не эмпирическая валидация.

## Локальный контракт

- нет внешних API, аналитики и серверного хранения;
- журнал хранится только в `localStorage` текущего браузера;
- есть JSON export/import и уничтожение локальной карты;
- контрзависимость не повышается до автономности;
- неподтверждённое Слово Субъекта не проходит `⊕-gate`;
- повторяющийся инвариант появляется только после трёх разных контуров.

Публичный маршрут: `https://lacinnik.github.io/Game-GDEYA/labs/core-separation/`.
