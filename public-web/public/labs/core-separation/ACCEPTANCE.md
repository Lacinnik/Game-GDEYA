# SEP-7×7 v0.2 · acceptance contract

1. Существуют ровно 49 уникальных координат `SEP(Lᵢ,Cⱼ)`.
2. Каждая координата содержит отдельный вопрос; все 7 законов и 7 контуров представлены.
3. Каждый ответ детерминированно даёт одно состояние `0..6`.
4. `counterdependence` всегда остаётся состоянием `2 · Различение` и не считается автономностью.
5. Пользователь может пройти один контур без заполнения остальных 42 узлов.
6. Результат не содержит единого процента сепарации и не оценивает личность.
7. ⊕-gate пропускает только один субъектно исполнимый шаг, не зависящий от согласия Другого.
8. Паспорт до фактического возврата сохраняет `Q=null`; после возврата `Q` становится наблюдаемым `0|1`.
9. Инвариант предъявляется только при повторении одного узла перехвата минимум в трёх разных контурах и остаётся гипотезой.
10. Ответы остаются локальными: нет внешних API и аналитики; доступны JSON export/import и уничтожение карты.
11. Страница работает на desktop и mobile, регистрирует локальный Service Worker и имеет офлайн-оболочку.
12. `TZAR-LANGUAGE-001` использует полный корпус `49 Азов × 24 Буки × 7 Передач` и профиль `SEP-7x7`.
13. Слово Субъекта, сингулярная формула и технический паспорт отображаются раздельно.
14. `CONDUCT` закрыт, пока субъект явно не подтвердил собранное высказывание.
15. Языковой паспорт сохраняет `O / S / I / R_g / C / Q`; до фактического возврата его `Q=null`.

Публичный релиз дополнительно требует успешных repository tests, public build, GitHub Pages deploy и проверки реального HTTPS-маршрута.
