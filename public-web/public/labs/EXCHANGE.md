# Общий обменный слой продуктовых студий

Версия контракта: `architectonica.ecosystem-exchange/1.0.0`.

## Зачем

Общий конверт позволяет переносить паспорта, решения, квитанции и журналы между продуктовыми студиями, сохраняя исходную схему внутри `payload`. Это совместимость транспорта, а не слияние методик и не единая база данных.

## Состав записи

- `schema`, `id`, `created_at` — идентификатор и время конверта;
- `source` — продукт, репозиторий, исходная схема и ID записи;
- `payload` — нетронутая запись производителя;
- `evidence_class` — заявленный класс свидетельства;
- `verified` — в этой версии всегда `false`.

JSON Schema опубликована в `axis-cycle/exchange.schema.json`. Реализация панели находится в `exchange-panel.mjs`; версия включена в общий Service Worker.

## Поток

1. Продукт экспортирует свой нативный JSON.
2. Панель принимает нативную запись с `schema` и `id`, оборачивает её либо импортирует уже готовый конверт/журнал.
3. Журнал хранится локально в браузере под общим ключом `architectonica.exchange-journal.v1`, ограничен 100 записями и может быть экспортирован/импортирован как `architectonica.exchange-journal/1.0.0`. GitHub Pages проекты на одном origin видят этот же журнал; другие origin/устройства обмениваются JSON-файлом.
4. Импорт не изменяет паспорт/решение в исходном приложении и не повышает статус продукта.

Источник распознаётся по зарегистрированным схемам, а не по странице-получателю. Неизвестная схема получает `unclassified-source` и репозиторий `unknown`; это не приписывает запись открытой пользователю студии.

Панель подключена к маршрутам `axis-cycle`, `certification`, `core-license`, `core-separation`, `creator-gate`, `diagnostics`, `facilitation`, `frontier`, `guide`, `meta-core`, `module`, `practice`, `rhythm`, `tactics` и `voidocr`. Эти 15 интерфейсов обслуживают объединённый каталог из 56 объектов; один интерфейс может представлять несколько продуктов.

РЕЗОН Field Check экспортирует конверт через `field-check/axis-bridge.mjs`; его `axis-return` сохраняет связь с исходной осью по `handoff_id`.

## Доказательность и приватность

Классы `none`, `self-reported`, `documented`, `independent-observation` описывают заявленный источник данных. Они не доказывают подлинность документа, личность наблюдателя, согласие участников или причинность результата. `Q` остаётся null до отдельного наблюдаемого возврата; самоотчёт не становится независимым фактом.

Панель не отправляет данные на сервер. Передача происходит только при явном экспорте/импорте файла или открытии ссылки. Не помещайте в пакет персональные данные, секреты и закрытые документы. Подписи, идентификация, централизованное хранилище, права доступа и юридическая приёмка не входят в эту версию.
