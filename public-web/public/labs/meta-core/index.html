03 · СВИДЕТЕЛЬСТВА

Не заполнять неизвестное догадкой

Устойчивость из VoidOCR не становится Q. Для проверки ворот нужен отдельно наблюдавшийся возврат по этому же объекту. Если его ещё нет — оставьте поля пустыми: результат будет HOLD_PROTOCOL.

Следующие оценки — явный ввод оператора, а не измерения программы. Допустимые значения: 0, 0.25, 0.5, 0.75 или 1. Основание каждой оценки укажите ниже.
