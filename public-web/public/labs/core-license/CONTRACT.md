# Core Architecture License Lab · 0.1

Рабочий конструктор объёма архитектурной передачи. Выпуск — **досье готовности**, а не лицензия.

## Инварианты

- `O`, `R_g`, `C` и инвариант вводит пользователь; система их не выводит.
- Пять финальных шлюзов по умолчанию имеют статус `unresolved`.
- Заявленный шлюз требует дословную формулировку и ссылку на источник, но остаётся `self-reported-declaration`.
- Состояние `ready-for-author-review` означает только полноту пакета для рассмотрения.
- `license_issued=false`, `verified=false`, `Q=null` при любом заполнении.
- Данные хранятся только в локальном браузере и могут быть выгружены в JSON.

## Не делает

Лаборатория не выдаёт лицензию, не формирует юридическое заключение или оферту, не назначает цену, канон и права доступа, не подтверждает результаты.
