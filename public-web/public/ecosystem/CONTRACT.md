# Контракт цифровой экосистемы · 0.1

`/ecosystem/` — управляющий слой внутри существующей Platform, а не новый самостоятельный продукт.

## Назначение

1. Сохранить идеи из переданного архива `gdeya_project` как отдельные объекты сборки.
2. Показать несущую линию `ГДЕЯ → РЕЗОН → Архитектоника Тактики → Живой модуль → Core Architecture License → Архитектор / Творец`.
3. Передавать выбранный объект в маршрут `/labs/axis-cycle/`, не заполняя за пользователя субъектные поля.
4. Различать рабочую стадию реализации и авторский статус.

## Паспорт объекта

- `O` — объект из реестра, который можно передать в Живую ось.
- `S`, `I`, `R_g`, `C` — не выводятся каталогом; их формулирует человек в ГДЕЯ.
- `Q` — `null` до отдельного фактического наблюдения.
- `delivery_stage` — техническая готовность к следующему шагу сборки.
- `canonical_status` — только явно закреплённый автором статус; иначе `unstated`.

## Граница 0.2

Все шесть продуктов несущей линии получили цифровые точки входа. Последние два являются подготовительными контурами: Core License Lab формирует досье объёма и пять явных шлюзов, а Creator Gate формирует запрос на рассмотрение. Они не назначают канон, юридические заявления, цены, права доступа и не подтверждают реальные результаты.

## Источник

Реестр собран по материалам переданного архива `gdeya_project`. Названия источников в `catalog.json` являются указателями происхождения, но не публичными ссылками и не заменяют авторскую редакцию материалов.
